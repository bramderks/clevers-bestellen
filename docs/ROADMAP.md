# Clevers Bestellen
## Product Roadmap

**Status:** Actief  
**Versie:** 0.1.0

---

# Visie

Clevers Bestellen wordt ontwikkeld als hét operationele platform voor ambachtelijke ijssalons.

De focus ligt op:

- eenvoud
- snelheid
- standaardisatie
- schaalbaarheid
- datagedreven werken

Iedere uitbreiding moet bijdragen aan deze visie.

---

# Fase 1 — Afgerond ✅

## Fundament

- Next.js
- React
- TypeScript
- Prisma
- PostgreSQL

## Kernfunctionaliteit

- Voorraadtelling
- Bestelengine
- OCR
- PDF-generatie
- Dashboard
- Weektaken
- Medewerkers (basis)

## Stabilisatie

- Opschonen project
- Herbruikbare componenten
- Centrale configuratie
- TypeScript strict
- Architectuurdocumentatie

# Fase 2 — In ontwikkeling

## Stap 1

### Historie

Doel:

Een volledig overzicht van alle bestellingen.

- filteren

- vergelijken
- rapportages
- opnieuw openen

## Stap 2

### Productbeheer

Doel:

## Stap 3

# Belangrijke ontwerpregels

Bij iedere nieuwe functionaliteit geldt:

- geen hardcoded vestigingen
- geen dubbele logica
- configuratie boven programmeren
- businesslogica centraal
- uitbreidbaar zonder refactor
- geschikt voor licentiëring

---

# Lange termijn

Clevers Bestellen moet uitgroeien tot een zelfstandig softwareproduct dat inzetbaar is binnen meerdere vestigingen en in de toekomst eventueel ook door andere ijsbedrijven onder licentie gebruikt kan worden.
